# ScrapNest — 端材ネスティング

レーザーカッターで出た板の端材を使い切るための Windows 用アプリです。
格子マットの上で撮った写真から端材の輪郭を寸法つきで起こし、部材の DXF を敷き詰めて、加工機に渡す DXF を出力します。

1. 端材を 1 マス 10 mm の格子マットに置いて写真を撮る
2. 輪郭を確認して、必要なら直す
3. 部材の DXF と個数を登録する
4. 自動で敷き詰める
5. 原点と向きを決めて DXF を保存する

## 導入

1. このページの **Code → Download ZIP** でダウンロードし、好きな場所に展開します。
2. フォルダーの中の **`run.bat`** をダブルクリックします。ブラウザが開きます。

- 初回は、必要なもの（[uv](https://docs.astral.sh/uv/)、Python、ライブラリ）を自動でダウンロードするので数分かかります。2 回目からはすぐ起動します。
- 「Windows によって PC が保護されました」と出たら、「詳細情報」→「実行」を選んでください。
- 終了するときは、黒いウィンドウを閉じます。
- 計算はすべて手元の PC で行います。写真や図面を外へ送ることはありません
  （起動時に新しい版が出ているかを GitHub へ見に行くだけです。環境変数 `SCRAPNEST_NO_UPDATE_CHECK=1` でやめられます）。

## 更新

新しい版が出ると、画面の右上に「新しい版 v… があります」と表示されます。

1. ScrapNest を終了します（黒いウィンドウを閉じる）。
2. フォルダーの中の **`update.bat`** をダブルクリックします。

設定（`config.json`）と作業中のデータ（`jobs` フォルダー）はそのまま残ります。
git で取得した場合は `git pull`、ZIP で取得した場合は最新の ZIP をダウンロードして入れ替えます。

## 使い方

作業は自動で保存され、ブラウザを開き直しても、アプリを起動し直しても続きから再開できます。
右上の「最初から」で写真と輪郭を消して次の端材に進めます（登録した部材を残すか消すかを選べます）。

### 1 写真

- マットは **1 マス 10 mm**（5 本ごとに太線）を前提にしています。
- 写真はファイル選択、ドラッグ＆ドロップ、貼り付け（Ctrl+V）で読み込めます。HEIC も読めます。
- **スマホから送る**: 同じ Wi-Fi のスマホで QR コードを読むと、撮った写真がそのまま届きます。
  初回は Windows のファイアウォールの確認が出るので「許可」してください。
- 読み込むと、見つけた格子が写真に重ねて表示されます。線が写真の格子に重なっていれば正常です。
- 格子が自動で見つからないときは「格子を手動で合わせる」で、交点 4 つとマス数を指定します。

撮影のコツ:

- **なるべく真上から**撮る。斜めでも補正しますが、真上に近いほど正確です（画面に傾きが出ます）。
- 板の**全体と、まわりの格子**が写るようにする。板が写真からはみ出すと、その部分は測れません（警告が出ます）。
- 板はマットに**ぴったり置く**。浮いていると、そのぶん寸法がずれます。
- 板の上や横に物を置かない（一緒に輪郭に入ってしまいます）。

### 2 輪郭

輪郭は直線と円弧でできています。

| 操作 | 働き |
|---|---|
| 頂点（丸）をドラッグ | 頂点を動かす。矢印キーで 0.1 mm ずつ（Shift で 1 mm） |
| 辺の中点（ひし形）をドラッグ | 直線 ⇄ 円弧 |
| 辺をダブルクリック | 頂点を追加 |
| 頂点を選んで Delete | 頂点を削除（前後が円弧なら 1 本の円弧にまとめる） |
| 矩形・傾いた矩形・円・3 点の円・楕円・多角形 | 「足す」「引く」で輪郭に足したり、切り欠いたりする |
| 測る | 2 点間の距離 |
| Ctrl+Z / Ctrl+Y | 元に戻す / やり直す |
| ホイール、右ドラッグ（または Space＋ドラッグ） | 拡大縮小、移動 |

- **板厚**を入れると、斜めから撮ったときに板の厚みで縁がずれて写るぶんを補正します（「検出し直す」で反映）。
- 写真に板が何枚か写っているときは、使う板を一覧か図の上で選べます。
- うまく検出できないときは「感度」を変えて検出し直すか、図形の道具で描いてください。

### 3 部材

- 1 ファイルが 1 つの部材です。線・円弧・円・ポリライン・楕円・スプラインを読みます（ブロックは展開します）。
- 寸法の単位は図面から読みます。外形寸法が実物と違うときは「単位」を直してください。
- **反転禁止**: 裏返して配置しません。レーザーの切り口は表と裏で幅が違うので、精度が要る部材に使います。
- 回転は「自由」「90° 刻み」「回転しない」から選べます。

### 4 敷き詰め

- **部材どうしの間隔**と**端材の縁からの余白**（どちらも初期値 3 mm）を守って配置します。
  輪郭の測定誤差があるので、余白は 2〜3 mm 以上を勧めます。
- 計算時間いっぱい、置き方を変えながら良い配置を探します。途中で止めても、その時点の最良の結果が使えます。
- 入りきらなかった部材は一覧に出ます。

### 5 出力

- **原点**: 最初は、端材を囲む四角の**左上の角**です。「原点を角へ」で四隅を選べるほか、
  図の上をクリックして好きな点（頂点・角・辺に吸着）にもできます。
- **向き**: 「辺を X 軸に合わせる」で選んだ辺が X 軸と平行になります。±90°、180°、角度の数値入力もできます。
- **端材の輪郭**: 位置合わせの目安として、部材と違う色（初期値は青）の線で入ります。入れないこともできます。
- 部材は元の DXF の図形をそのまま（円弧は円弧のまま）移動・回転して書き出します。
- **写真に写した面を上にして**加工機に置いてください。裏返すと形が合いません。

#### SmartDIYs Cutter で使うとき

SmartDIYs Cutter は、DXF のレイヤーではなく**線の色ごと**にレイヤーを分けます。
端材の輪郭は部材と違う色で出力されるので、読み込んだあと「レイヤーパラメータ」を開き、
輪郭の色のレイヤーで **「加工なし」** にチェックを入れてください。輪郭は切られなくなります。

## 精度の目安

- 格子の当てはめ誤差は 0.1〜0.2 mm 程度（画面に表示されます）。
- 輪郭は、縁がはっきり写っていれば 0.5 mm 前後です。影、ばり、マットの汚れ、板の浮きで悪くなります。
- 斜めから撮ったときは、板厚を入れると「板を大きく見積もらない」側に補正します。
  カメラ側の縁は、板の側面が写るぶん（最大で 板厚 × tan(傾き) 程度）小さめに出ることがあります。
- 大事な寸法は「測る」で確かめるか、実物をノギスで測って比べてください。

## 既知の制限

- 端材は 1 回に 1 枚です。
- マットの格子が擦れて消えている所は、板と区別がつきにくくなります（輪郭を手で直してください）。
- 板と同じくらいの大きさの物（工具など）が板に重なっていると、一緒に輪郭に入ります。
- DXF は R2010 形式で出力します。

## 設定とファイル

| 場所 | 中身 |
|---|---|
| `config.json` | 間隔・余白・板厚・出力先などの設定（自動で保存） |
| `jobs/last/` | いまの作業（写真、輪郭、部材、敷き詰め結果） |

## 開発者向け

```
uv run python -m scrapnest             # 起動（--port 8765 / --no-browser / --fresh）
uv run pytest                          # 検査
uv run pytest tests/test_e2e.py        # 画面を通しで操作（初回は uv run playwright install chromium）
uv run python tests/make_synthetic.py  # 正解つきの合成写真を作る
```

実物の写真を使う検査（`tests/test_e2e.py` と `test_vision.py` の一部）は、`tests/data/scrap_sample_01.png` に
写真を置いたときだけ走ります（この写真はリポジトリには入っていません）。

```
scrapnest/
  vision/grid.py      格子の検出 → 写真と mm の対応、カメラの位置
  vision/segment.py   真上から見た画像への補正、板の領域の切り出し
  vision/outline.py   縁の位置合わせ、板厚の補正
  vision/arcfit.py    点列 → 直線＋円弧
  geom/outline.py     輪郭のモデル、図形を足す・引く
  dxfio/              部材 DXF の読込、結果の書き出し
  nest/               敷き詰め（raster.py: 置ける位置の計算、engine.py: 探索、verify.py: 検査）
  server.py jobs.py   画面のためのサーバーと、作業の状態
  update.py           版の確認
  static/             画面（HTML / CSS / JavaScript）
tools/update.ps1      更新の本体（update.bat から呼ばれる）
```

しくみの要点:

- 板は反射で色が定まらないので、色ではなく「あるはずの格子線が見えない」ことを手がかりに板を見つけます。
- 敷き詰めは、端材と部材を細かい格子の画像にして「重ならずに置ける位置」をまとめて求め、
  置く順番と向きを変えながら繰り返します。最後に元の図形で間隔と余白を検査します。

版を上げるときは `pyproject.toml` の `version` を変えます（画面の右上と、更新のお知らせに使われます）。
